<p class="project-meta">ML systems · Query analysis · LLM integration · Full-stack demonstration</p>

Smart SPARQL Advisor helps users formulate more practical database queries by connecting query analysis and performance prediction with context-aware assistance. It demonstrates how research models can become an interactive tool rather than remaining an offline experiment.

## Contribution

- Integrated query parsing, feature extraction, model inference, and database access.
- Connected predictive models with an LLM to provide context-aware query suggestions.
- Contributed to backend and frontend integration.
- Helped transform research models into a working interactive demonstration.
